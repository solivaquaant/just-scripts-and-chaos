# Just scripts and chaos
> A chaotic collection of self-made Infosec scripts and tools - useful, experimental, and a bit unpredictable.

## Overview
This repository contains various scripts and tools related to information security, penetration testing, and network experimentation. These are primarily **self-written** and intended for learning, experimentation, and personal projects.

> ⚠️ Use responsibly. Scripts are provided as-is.

## Scripts and tools

| Script | Description |
|--------|-------------|
| `ftp-scan.py` | A GUI-based FTP scanning tool with anonymous login support. It allows scanning a single target or multiple targets from a file and exports the results as an HTML report showing discovered files. |
| `check-urls.py` | A script that checks connectivity to IP addresses listed in a file and stores the results into separate output files for successful and failed connections. |
